# Student Management System

A beginner-friendly Java web application using MVC, Servlet, JDBC and MySQL.

## Technologies
- Java
- Jakarta Servlet
- JDBC
- MySQL
- JSP
- HTML/CSS
- Maven
- Apache Tomcat

## Features
- Add Student
- View Students
- Delete Student

## Setup
1. Create the `studentdb` database using `database.sql`.
2. Open `src/main/java/util/DBConnection.java`.
3. Replace `your_password` with your local MySQL password.
4. Import as a Maven project.
5. Use Tomcat 10+.
6. Run the project on the server.

Do not commit real database passwords to GitHub.
